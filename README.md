Starbie 🐾
Starbie is a little digital pet that you can control with buttons and movement. It's kinda like a tiny Tamagotchi that sits on your desk!

What It Does
Shows a little pet on a small screen
Lets you interact with the pet using buttons
Uses movement sensors to control stuff
Can show animations and different things on the screen
Parts
ESP32-C3
OLED screen
MPU6050 motion sensor
DHT11 temperature and humidity sensor
2 buttons
Custom PCB
How It Works
The ESP32-C3 is basically the brain of Starbie. It runs the code and talks to the screen and sensors. The buttons let you interact with your pet, and the motion sensor can detect when you tilt or move it.

PCB Design
I'm using KiCad to design the circuit board for Starbie. The board will hold all the parts together and connect them.

Code
The code is made for the Arduino IDE. It controls the screen, sensors, buttons, and pet animations.

Progress
I'm working on getting the PCB design and code ready. I don't have the physical board yet, so I still need to build it and test everything once I get the parts.
